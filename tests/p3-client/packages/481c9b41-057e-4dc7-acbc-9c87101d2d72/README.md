# TEST_ONLY P3 connected Client fixture

Only `tests/p3-client/**` is authored/generated. Parent alone installs the absolute `readyTarget` printed by `node tests/p3-client/build.mjs`. Every build creates a new UUID package and ModuleLoader factory identity; generated directories are immutable. No replacement server, model calls, production build, OS/shell runtime changes, Profile edits or git commit.

This disposable renderless acceptance unit intentionally omits artwork and locale display resources. It adds no product UI or model Tools. Dependencies use the same native Typert/strict JSON codec pattern as the already verified P2 fixture. Browser factory imports only builtin Zod; no runtime feature imports.

## Prerequisites / run

- Production main 0.3.0-alpha.2 and new data Client, actual connected GUI, both independent TEST_ONLY adapters installed and READY; no adapter failure armed.
- Production financeOperations snapshot MUST be awaited `binding:null, revision:19`; fixture never mutates it.
- Parent installs one P3 fixture at a time. Native Client runs once per activation, discovers public SlotRegistry entries and resolves the actual `entry.inject().updateDataPolicy` from main, configuration and activation slots. Missing callback is a preserved **FAIL / PRODUCTION_DATA_CALLBACK_MISSING_REFRESH_REQUIRED**. Refresh the ordinary GUI and use a fresh package for a new attempt; never inject a fixture replacement callback.
- Resource holds use `ctx.resources.source`, `subscribe`, and `pin` with owned AbortControllers. Waits are subscription-driven with bounded deadlines, not polling/sleeps/retries. There is no DOM, mouse, screenshot, Session navigation, composer access or user draft read.

## Host native Remote API

Namespace `remote.financeP3ClientTestOnly` is mounted then explicitly injected. It exists solely for this disposable fixture. No business Service is invoked through Inspect.

- `checkpoint({stage})`: bounded safe activation stage, append journal + checkpoint.
- `setup({})`: allocate one native modeler Agent in UUID-owned directory, actual preset mount and exact original role grant check. Return runId, ownedScopeId, roleId, source keys, status, public policy/data and path-free null/19 baseline; no cwd or user input.
- `queryOwned({runId})`: actual `ctx.tools.execute(finance_data_query, agent)` with exact owned Agent and fixed toy query; return only synthetic values/provenance status.
- `toggleToyState({runId,state:'READY'|'NOT_AUTHORIZED'})`: only installed TEST_ONLY MCP controller. No credentials/production adapter control.
- `report({})`: authoritative real Host public financeData catalogue and fixture stage/status. Read-only, no user draft.
- `finalize({runId,clientReportJson})`: fresh current-revision CAS subtraction of only owned scope on the two known toy adapters; preserve concurrent other bindings, never stale-restore original policy. Restore original toy states; marker/exact identity fenced Agent disposal; zero native model turns; awaited default binding still null/19. Retain files/history. CAS conflict is a cleanup FAIL, not a retry/overwrite.

All methods use native strict Typert JSON codec factories. Unary RemoteResult wrappers are unwrapped once by the fixture; production updateDataPolicy must itself return unwrapped PolicyResult.
