# P3 native MCP compatibility — TEST_ONLY, not a Manager

This isolated test uses the **actual shipped `@deepseek-ai/dsh-mcp-client`** via its documented declarative bundle configuration. It does not implement a second MCP manager, fake Harness Tools, a private connection supervisor, or production financial-source support. Synthetic TOY FY2024 USD revenue is **2.2 million** (EBITDA 0.44 million); license/classification is TEST_ONLY, not real commercial data.

## Parent-only installation sequence

1. Run the builder with the **actual bundled Node executable**. It creates unique immutable packages and prints `nativeTarget`, `probeTarget`, `auditTarget`, and exact result paths. The builder never installs anything or starts the server.
2. Parent installs `nativeTarget` using the native Plugin Manager. It is a **configuration-only bundle**; the existing native MCP plugin alone negotiates stdio, owns the process, discovers/registers tools, and owns reconnect/disposal. No install scripts or new dependencies are declared. Its command is the actual builder Node executable and its sole argument is its own absolute server entry path.
3. Parent inspects the installed native row Config and native Tool schemas, then installs `probeTarget`. This separate TEST_ONLY Host plugin invokes only the two fixed native names through **public `ctx.tools.execute`**. It creates one real Finance modeler Agent solely for negative visibility/dispatch tests, never submits a turn, preserves history, and disposes only that exact marker-fenced Agent. Read `connectionResult`.
4. Parent removes the native config bundle (and may remove the finished Host probe) through the native Plugin Manager; wait for its applied/quiescent removal result. Then parent installs `auditTarget`. Read `unloadResult` to verify schemas disappear and real public dispatch rejects previously proven native calls while their schemas and definitions are absent. The audit cannot unload or restart anything itself.
5. Parent removes the completed audit/probe bundles. Retain package fixtures and evidence; nothing here deletes files, history, or user data.

Do **not** mark connection PASS until the actual Host report passes, or unload PASS until the audit passes. Local tests are not actual native connection evidence. No package is installed by this authoring task. Original SVG plus meaningful English/Chinese bundle/Host metadata are included; native plugin-row metadata remains the shipped plugin's own. Browser-rendered titles/icons require parent verification and are not claimed by static checks.

## Supported specific APIs vs unsupported gap

Inspected shipped native README and built `lib/index.js` (runtime 0.2.1-rc.5) prove configuration fields: `serverName` matching `[A-Za-z0-9_-]{1,32}`, `transport: stdio`, `command`, `args`, `failOnStartupError`, `toolCallTimeoutMs`, `maxInstructionBytes`, and bounded `reconnect`. One native entry is inserted; no profile, runtime, root package, model, network, OAuth or credentials are modified here. SDK negotiation uses its 60-second default; the plugin exposes no separate startup/discovery deadline. Tool calls use 3 seconds; probe calls use a 5-second abort deadline; reconnect has two attempts, 250 ms initial/1 second maximum delay. The server exits on stdin closure and has a 10-minute abandonment ceiling / 256-frame cap. Native plugin owns all recovery.

The public ToolRuntime signature is `execute({callId, name, arguments, signal, agent?, parent?})`. It enforces pre-policy, monotonic guards, dispatch, and post-policy. The directly human-authorized Host connection test may use the public optional-Agent contract; it is **not** a FinanceRole delegation. A temporary owned guard proves the actual public dispatcher still denies. Native MCP tools remain absent and denied by actual dispatch in the FinanceRole (without assuming a particular serialized error-code field), and general Node/Shell/raw-file tools are not added to that role.

**No safe FinanceDataAdapter bridge is implemented.** The actual FinanceData registry passes an Adapter `query(validatedQuery, {signal, requestId})`, not an exact Agent or originating ToolExecution token. The FinanceRole floor masks global raw MCP Tools. No inspected public contract supplies an authorized fixed-tool delegation that can preserve that Agent's floor and tool approval/sandbox policy. Omitting the Agent, substituting an unrelated scope, using `definition.execute`, or calling a private connection would bypass the intended role boundary. No scopes/bindings/source policies are edited; no grant is claimed. Manager remains **NOT_AVAILABLE** and P3 Manager must not be marked PASS. The connection-state helper is probe-local evidence, not a provider registration: READY requires actual successful native ping **and** read; an observed failed native call yields UNAVAILABLE with `verifiedAt` and subsequent real ping/read can recover. The failure test is a native MCP `isError` for unsupported synthetic input, not proof of a transport crash/reconnect.

## Endpoint and local conformance tests

The tiny local Node server implements actual newline-delimited JSON-RPC MCP `initialize` with legacy `2025-06-18` negotiation, `notifications/initialized`, protocol `ping`, `tools/list`, `tools/call`, and safe ignored cancellation/progress notifications. It advertises only `ping` and `financial_statements`, both read-only; no server instructions, resource endpoints, arbitrary URLs/paths/keys, model code, Shell or upstream scripts. Only its package-owned fixed JSON fixture is read. Output is bounded; no exception payloads or secrets are logged. It deliberately does not implement unsupported modern extensions or prompt/resources capabilities.

Run `node --test tests/p3-native-mcp/protocol.test.mjs` and `node tests/p3-native-mcp/build.mjs` with the bundled Node. Tests are in-process protocol/frame-parser tests; they do **not** spawn the endpoint, use named pipes, install plugins, access network/models/credentials, or claim native MCP connectivity. SDK runtime modules live inside Electron ASAR and cannot be resolved by standalone Node, so this self-contained protocol endpoint uses no added dependencies.
