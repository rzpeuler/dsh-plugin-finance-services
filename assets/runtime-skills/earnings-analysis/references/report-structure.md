# Report Structure and Templates

This document provides complete page-by-page templates and formatting requirements for the earnings update DOCX report.

**REPORT STRUCTURE:**

[Current Date]

Rating: [MAINTAIN/RAISE/LOWER] [RATING]

## FORMATTING REQUIREMENTS

### 1. Page 1 Requirements
- Clear rating (MAINTAIN OUTPERFORM, RAISE TO BUY, etc.)
- Updated price target prominently displayed
- Summary table with old/new estimates
- 3-4 paragraph-length bullets with ■ character

### 2. All Tables Requirements
- Source line at bottom
- Clear column headers
- Shading for header rows

### 3. All Charts Requirements
- "Figure X - [Title]" caption above
- "Source: [Source]" line below
- Professional styling

### 4. Year Notation
- Use A for actual (Q3'24A)
- Use E for estimate (Q4'24E)

### 5. Writing Style
- Lead with numbers ("Revenue grew 15% to [source currency] 1.2B" not "Strong revenue growth")
- Use "vs." not "versus"
- Be direct and concise
- Focus on what's NEW

### 6. Source and Provenance Requirements ⭐⭐⭐
- Record the source/tool or user-file name, source/document date, reporting period, currency/unit, and page/section/field where available.
- Use consensus only when supplied by the user or returned by an explicitly configured and authorized capability with an as-of date; otherwise mark it `UNSOURCED` / `NOT_CONFIGURED` and do not claim a beat/miss.
- Use only source-reported guidance and key metrics. If a needed source is missing, mark the field `UNSOURCED` / `NOT_CONFIGURED`.
- Do not require or create external hyperlinks. Preserve source URLs only when present in supplied material or an authorized result; do not browse to test them.

## Citation Examples for Specific Content

### For Beat/Miss Analysis:
```
[Metric] of [source currency and amount] [beat/missed] [user-provided estimate or authorized consensus] by [amount] ([percentage])¹

¹ [Source/query or user file], as of [date], reporting period [period], currency/unit [unit]; actuals from [source/user file and date]
```

### For Guidance:
```
Management [raised/maintained/lowered] [metric] guidance to [source-currency range] from prior [source-currency range]²

² Current guidance: [available source/user file and date]; prior guidance: [available source/user file and date]
```

### For Key Metrics:
```
[Issuer metric] changed by [amount/percentage]³

³ [Available query result or user file], [date/period], [page/section/field if available], [currency/unit and provenance]
```
