## Source-family deduplication

Eastmoney `push2` and `push2his` are one provider family; endpoint/subdomain separation is not independent-source corroboration. THS page and other THS APIs are one operator family. TDX TCP nodes and TDX official daily ZIP are different capabilities but the same operator family; TCP K-line was not demonstrated and is not an Adapter fallback. The three adapters are separate software identities, not three independent confirmations for every field.

## Capability gaps / decisions deferred

- The current FinanceData observation schema has no per-row trading-date column for a daily-series period. A multi-day price history query cannot faithfully return many bars without an additive time-series contract. The candidates deliberately constrain themselves to one day; they do not map a multi-day array into an invented observation.
- EPS per-share unit is represented by existing `currency_per_share` / CNY / ones; no ordinary currency-total unit is used.
- Volume share/lot conversion, amount scope/currency, date-bounded source revision proof, historical consensus vintages, complete financial statements, news, and corporate actions are not declared by these adapters.
- No source-specific official license/contract or AI-processing/session-log permission evidence is available in the reviewed audit package. All adapters therefore remain `UNASSESSED` and cannot pass real queries unless a trusted, scope-specific assessment is separately recorded.
