# P3 — 数据可扩展基础

状态：ACCEPTANCE_CRITERIA_DEFINED / NOT_IMPLEMENTED。前置P2关键标准已通过；本表在P3实现前建立。当前商业查询仍NOT_CONFIGURED，不能将两个TEST_ONLY Adapter视为真实金融E2E。

## 关键验收标准

| ID | 操作与预期 | 必需证据 | 当前结果 |
|---|---|---|---|
| P3-CONTRACT | 稳定、版本化的Capability/Adapter/SourcePolicy/Result接口；核心身份/期间/asOf/币种/单位/口径/来源/观察时点/授权分类 | 独立Host接口及严格输入/输出测试，不建全市场巨型Schema | NOT_RUN |
| P3-CATALOG | 覆盖原任务所列14类能力，供应商专用扩展可明确不等价 | 稳定ID与来源/角色/允许源映射；无数据不伪造实现 | NOT_RUN |
| P3-EXTERNAL | 两个独立DSH测试Adapter插件，一MCP风格、一REST/文件风格，至少共享一capability | 原生安装/注册/查询/卸载；不改10个Agent源码 | NOT_RUN |
| P3-SELECT | 按capability+market+required fields+asOf+purpose选择，过滤覆盖/授权/质量/新鲜度后确定排序 | 多来源能力各异的反例，不从全局供应商优先级推断等价 | NOT_RUN |
| P3-FALLBACK | 可诊断的来源切换和fallback，记录每步拒绝/错误/降级原因 | 实际API结果、错误路径和native UI资源状态，不固定成功假文本 | NOT_RUN |
| P3-SEMANTICS | 单位缩放、期间/会计口径/修订分开处理，币种无有效FX依据不换算 | 同字段不同源/口径独立观察，不静默去重、均值化或混合 | NOT_RUN |
| P3-PIT | availableAt/retrievedAt/sourceAsOf/period语义明确；历史查询不得用未来可得数据回填 | PIT、未来观察、修订/重述反例 | NOT_RUN |
| P3-SOURCE-AUTH | 原角色/Session/source/capability授权逐次检查，新增Adapter不自动扩大所有角色权限 | 模型schema与实际dispatcher拒绝，writer仍无金融查询 | NOT_RUN |
| P3-CREDENTIALS | 配置仅保存原生credential引用，状态按实际Host而非配置存在推定 | 无授权显示NOT_AUTHORIZED；UI/日志/报告不导出凭据 | NOT_RUN |
| P3-MCP-NATIVE | 只复用发行版真实可用的原生MCP注册/连接/状态机制，不造第二个通用Manager/OAuth | 现行Inspect/包exports核对、可用API实际验证；宿主未提供时保留明确兼容缺口，不假PASS | NOT_RUN |
| P3-UI | Data Sources显示实际注册、授权、覆盖、可用性/错误/来源选择；配置改变由Host权威投影 | 当前GUI的真实resource/生产callback复验，视觉另标；无静态运行卡片 | NOT_RUN |
| P3-LIFECYCLE | Adapter注销移除能力与UI、取消自有inflight；过期版本/晚回调不覆盖现态 | 原生卸载、重装及并发/取消反例，只清理自有记录 | NOT_RUN |
| P3-NO-FAKE | TEST_ONLY保持明确标记；公开新闻不得冒充screening/consensus/NAV | 返回契约、拒绝/无凭据报告及UI一致 | NOT_RUN |
| P3-TEMPLATE | 提供可独立接入的Adapter示例和扩展文档，新增供应商无需改角色/核心UI | 独立开发者模板构建及原生注册烟测 | NOT_RUN |

## 保留边界

- 不修改DSH Core、其他业务项目、Profile源码文件；只通过原生Plugin Manager管理本项目插件。
- 内部Review不授予数据/Shell/外部副作用权限。发布、交易、正式GL、客户通信和KYC签字仍永久禁止。
- 原源商业Provider未授权不等于功能不存在；无原生Manager接口不伪造连接成功。P3不能因测试Adapter通过而抹去实质宿主兼容缺口。
- 每次失败及修复后新运行分别保存，不将注册数量、工具定义或UI可见当查询执行成功。
