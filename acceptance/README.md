## 每阶段记录格式
- 开始/结束时间与代码 revision；先列测试 ID、测试前提、预期行为和关键性。
- 实施文件与实际命令；保存 stdout/stderr、退出码、测试计数、原生运行证据。
- 分开列：静态审计、单元测试、宿主集成、真实 UI 操作、真实金融数据 E2E。
- 失败与跳过项包含原因和下一步；修复保留首次失败，新增复测记录，不抹去历史。
- 人工授权缺失标 `NOT_CONFIGURED`；宿主接口缺失标 `BLOCKED` 或已实现替代的 `PARTIAL`。
- 不因未授权商业源停止不依赖它的独立工作，但不把后续阶段记为已验收。
