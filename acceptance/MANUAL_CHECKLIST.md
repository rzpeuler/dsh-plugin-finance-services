# 界面验收操作手册（P6 / P5-UI）

本手册给出一组**可由人执行**的验收步骤。每步都写明预期观察、失败时如何记录。机器证据见[缺口台账](gap-ledger.json)：凡是本手册覆盖的项，在台账里都是 `NOT_RUN`，直到有人保存观察结果。

> 前置：本 Bundle 已通过原生 Plugin Manager 以链接方式安装并 `application: applied`。若刚改过源码，先 `pnpm run build` 再重装，否则页面仍加载旧产物。

## 记录方式

每步结束时把结论写入一个新的 `acceptance/P6-manual-<日期>-<序号>.md`，包含：

1. 步骤编号与时间；
2. 实际看到的内容（截图可选，路径写清楚）；
3. 与预期的差异（逐条）；
4. 结论：`PASS` / `FAIL` / `BLOCKED`（`BLOCKED` 必须写原因）。

不允许只写"界面正常"——每步都要有可核对的具体观察。

## A. 打开与定位

| # | 操作 | 预期 |
|---|---|---|
| A1 | 刷新页面，左侧导航出现 **Financial Services** 入口，点击 | 打开工作台面板；不发生整页报错 |
| A2 | 观察导航项数量与位置 | 只有一个金融入口；未替换或隐藏原生 session/plugins 面板 |
| A3 | 面板顶部有"金融工作台"标题与刷新按钮 | 中英文随系统语言切换（可在 Settings 切换语言后回看） |

失败记录：截图 + 浏览器控制台报错文本（不要粘贴含 token 的内容）。

## B. 工作台六段

| # | 操作 | 预期 |
|---|---|---|
| B1 | 工作区卡 | 显示 `binding: bound/unbound` 与 revision；未绑定时显示 UNBOUND，不得显示成就绪 |
| B2 | 角色卡 | 主 Agent 10、Worker 30 |
| B3 | 数据源卡 | 适配器数、策略数、revision；无适配器显示 0，不显示"已连接" |
| B4 | Runs 卡 | 无记录时显示"尚无运行记录阶段"；有记录时列出 run、分类、检查点状态、成果数 |
| B5 | 成果卡 | 无记录时显示空态；有条目时显示路径、字节、分类、哈希前缀 |
| B6 | 审核队列卡 | 会话、检查点、待审、已决与 revision；空队列显示空态 |
| B7 | 点"刷新" | 数据重新读取；任一卡片失败时其余卡片仍显示，并出现"部分卡片读取失败" |

## C. 审核面板（只读）

| # | 操作 | 预期 |
|---|---|---|
| C1 | 找到"审核队列"面板（工作台下方） | 顶部显示策略 id、版本、锁定边界数、外部副作用 `DISABLED` |
| C2 | 若有待审项 | 每个会话一行，标注"会话在线/已结束"，逐检查点显示 `APPROVED` 或拒绝原因 |
| C3 | 检查是否有任何"批准/拒绝"按钮 | **不应存在**；本页面只读，批准由 Host 记录 |
| C4 | 断网或让服务不可用后点刷新 | 显示"上次读取失败…"并保留错误码；不得显示假成功 |

## D. 数据源与策略

| # | 操作 | 预期 |
|---|---|---|
| D1 | 打开数据源卡片 | 显示适配器状态、许可类别、TEST_ONLY 标记、覆盖字段/市场 |
| D2 | 尝试添加策略但把来源 key 写成角色未允许的值 | Host 拒绝；界面显示拒绝原因，不显示"已保存" |
| D3 | 关闭来源策略编辑（未保存） | 不发生写入；刷新后状态不变 |

## E. 设置与依赖

| # | 操作 | 预期 |
|---|---|---|
| E1 | 打开插件详情页 | 看到 `finance-data`（超时/并发）与 `finance-review`（策略 id/customJson）两个可配置行 |
| E2 | 修改 `finance-review.policyId` 后保存 | 仅对新服务生命周期生效：重启该行/重装后审核面板的策略 id 改变；已记录决定不变 |
| E3 | 检查是否有任何凭据/API Key 输入框 | **不应存在** |

## F. 窄屏、主题、键盘

| # | 操作 | 预期 |
|---|---|---|
| F1 | 窗口缩到约 520px 宽 | 不出现横向滚动条；卡片纵向堆叠 |
| F2 | 切换深色/浅色主题 | 文字与错误提示保持可读，不出现白底白字 |
| F3 | 仅用 Tab 键 | 刷新按钮与策略表单可依次聚焦，焦点可见 |

## G. 生命周期

| # | 操作 | 预期 |
|---|---|---|
| G1 | 在 Plugin Manager 中**禁用**本 Bundle | 面板消失；`finance-review` 行不再可查 |
| G2 | 重新**启用** | 面板恢复；此前记录的审核仍在队列中 |
| G3 | **卸载**后检查工作目录 | 用户文件与 DSH 历史仍在 |
| G4 | 重装并刷新 | 绑定与审核索引恢复；若目录已移动则提示重新绑定 |

## 结论如何进入验收

把上述各步的 `PASS/FAIL/BLOCKED` 汇总后更新 `acceptance/P6-results.json` 的 `criteriaResults` 与 `browserRendered` 字段，并在 `acceptance/P6.md` 追加一节引用你的记录文件。**在完成之前，P6 不标通过**；同理 P5 的 UI 项与 OS 重启项也不会因为本手册存在而变绿。
